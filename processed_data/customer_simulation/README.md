# Linked customer simulation

This branch is generated by [`scripts/build_synthetic_customers.py`](../../scripts/build_synthetic_customers.py)
from unchanged ABCD records. For complete derivation steps, table provenance,
counts, and limitations, see the [processed-data guide](../README.md).

The key artifact is [`synthetic_retail.sqlite`](synthetic_retail.sqlite), whose
schema is [`sql/synthetic_retail_schema.sql`](../../sql/synthetic_retail_schema.sql).
It contains 808 synthetic customer identities linked to 1,148 ABCD-derived
order scenarios and 1,273 items. `source_cases.jsonl` maps each record back
to its original `convo_id`; `manifest.json` stores the fixed seed and counts.

`multi_request_cases.jsonl` contains 32 newly composed prompts with no
reference labels. `rewritten_conversations.jsonl` changes identity text in
the source role-play dialogue, while preserving its original turn order and
actions for comparison. It is not a new independently observed conversation.

All synthetic identities and any cross-conversation customer grouping are
project-created. Original missing order values remain missing. Do not treat
this database as real customer data or a production authentication system.
